# The 6502 CPU (as used in the NES's Ricoh 2A03)

All facts here are **[standard]** 6502 documentation unless marked. Cycle counts are the documented values for
the NMOS 6502; check them before relying on exact timing.

## 1. The machine in one paragraph
The 6502 is an 8-bit CPU with a 16-bit address bus (64 KB, $0000-$FFFF). It has three 8-bit working registers
(A, X, Y), an 8-bit stack pointer, an 8-bit status register and a 16-bit program counter. Almost everything
goes through A. Memory is little-endian: a 16-bit value is stored low byte first.

The NES CPU is a Ricoh 2A03 (NTSC) / 2A07 (PAL): a 6502 core plus the APU (sound) and I/O, with the decimal
(BCD) mode removed. NTSC CPU clock: 1.789773 MHz; PAL: 1.662607 MHz **[verified 2026-11-25, APU page]**.

## 2. Registers
| Register | Size | Use |
|---|---|---|
| A (accumulator) | 8 | arithmetic, logic, most loads/stores |
| X | 8 | index register, counters; the only register for TSX/TXS |
| Y | 8 | index register, counters; the only index for (zp),Y |
| S (stack pointer) | 8 | offset into the stack page $0100-$01FF; points at the next free byte |
| P (status) | 8 | flags (below) |
| PC | 16 | address of the next instruction |

## 3. Status flags (P), bit 7 to 0: N V - B D I Z C
- **N** (bit 7) negative: copy of bit 7 of the result.
- **V** (bit 6) overflow: set when ADC/SBC give a signed result outside −128..127; BIT copies memory bit 6 here.
- bit 5: unused (reads as 1 when P is pushed).
- **B** (bit 4) "break": exists only in the copy pushed to the stack (1 for BRK/PHP, 0 for IRQ/NMI).
- **D** (bit 3) decimal: on the 2A03 it can be set/cleared but ADC/SBC ignore it (no BCD). Init code still
  does CLD for compatibility with generic tools **[verified 2026-11-25, Init code]**.
- **I** (bit 2) IRQ disable: 1 = ignore IRQs (NMI can't be disabled this way).
- **Z** (bit 1) zero: result was 0.
- **C** (bit 0) carry: carry out of ADC / shifts; "no borrow" for SBC/CMP.

## 4. Addressing modes
| Mode | Example | Meaning |
|---|---|---|
| Implied | `INX` | operand is built in |
| Accumulator | `ASL A` (ca65 also accepts `ASL`) | operates on A |
| Immediate | `LDA #$10` | the value $10 itself |
| Zero page | `LDA $10` | memory at $0010 (1-byte address, faster, smaller) |
| Zero page,X / ,Y | `LDA $10,X` | ($10 + X) wrapped within $00-$FF; ,Y only for LDX/STX |
| Absolute | `LDA $2002` | memory at $2002 |
| Absolute,X / ,Y | `LDA table,X` | address + X (or Y); +1 cycle on reads that cross a page |
| Indirect | `JMP ($FFFC)` | JMP only: jump to the 16-bit address stored there |
| Indexed indirect | `LDA ($10,X)` | pointer at ($10+X) in zero page; rarely used |
| Indirect indexed | `LDA ($10),Y` | 16-bit pointer at $10/$11 (zero page), plus Y; the workhorse for pointers |
| Relative | `BNE loop` | branches: signed 8-bit offset from the next instruction (−128..+127 bytes) |

`#` is the most common beginner bug: `LDA #$20` loads the number $20; `LDA $20` loads the byte stored at $0020.

## 5. The 56 official instructions (flags changed)
Load/store/transfer
- `LDA LDX LDY` (N Z) load; `STA STX STY` (none) store.
- `TAX TAY TXA TYA TSX` (N Z); `TXS` (none) — sets the stack pointer.

Arithmetic
- `ADC` (N V Z C): A = A + M + C. Clear carry first (`CLC`) for a plain add.
- `SBC` (N V Z C): A = A − M − (1 − C). Set carry first (`SEC`) for a plain subtract. After SBC, C = 1 means
  "no borrow".
- `INC DEC` memory, `INX INY DEX DEY` (N Z). They do NOT touch carry.
- `CMP CPX CPY` (N Z C): compute reg − M and set flags only. C = 1 if reg ≥ M (unsigned), Z = 1 if equal.

Logic and bits
- `AND ORA EOR` (N Z).
- `ASL` (N Z C) shift left, bit 7 → C, 0 → bit 0. `LSR` (N=0, Z, C) shift right, bit 0 → C.
- `ROL ROR` (N Z C) rotate through carry.
- `BIT` (N V Z): Z = (A AND M) == 0; N = M bit 7; V = M bit 6. Does not change A. `BIT $2002` is the classic
  way to test the PPU's vblank flag (bit 7 → N) without disturbing A.

Branches (test one flag; all relative)
- `BEQ` (Z=1) `BNE` (Z=0) `BCS` (C=1) `BCC` (C=0) `BMI` (N=1) `BPL` (N=0) `BVS` (V=1) `BVC` (V=0).
- After `CMP #n`: BEQ = equal, BNE = not equal, BCS = A ≥ n, BCC = A < n (unsigned). For signed compares
  you need N and V together; avoid with beginners unless needed.
- A branch that must reach farther than 127 bytes: invert it and branch over a `JMP`.

Jumps, subroutines, interrupts
- `JMP` (none): absolute or indirect. Indirect bug: `JMP ($xxFF)` reads the high byte from $xx00, not the next
  page — never put a JMP vector across a page boundary.
- `JSR` (none): pushes (return address − 1), jumps. `RTS` (none): pulls it, adds 1.
- `BRK` (B, I): software interrupt through the IRQ vector. `RTI` (all): pulls P then PC.

Stack
- `PHA PHP` push A / P; `PLA` (N Z) pull A; `PLP` (all) pull P.

Flags
- `CLC SEC CLI SEI CLD SED CLV`. (There is no SEV.)

Other
- `NOP`.

Unofficial ("illegal") opcodes exist and some emulators support them; don't teach them to a beginner.

## 6. Common cycle counts [standard]
| Instruction | Cycles |
|---|---|
| LDA # / LDX # / LDY # | 2 |
| LDA zp | 3 |
| LDA abs | 4 |
| LDA abs,X / abs,Y | 4 (+1 if a page is crossed) |
| LDA (zp),Y | 5 (+1 if a page is crossed) |
| STA zp / abs / abs,X / (zp),Y | 3 / 4 / 5 / 6 (stores never get the page-cross discount) |
| INX, DEY, CLC, TAX... | 2 |
| INC zp / INC abs | 5 / 6 |
| Branch | 2 not taken, 3 taken, 4 taken across a page |
| JMP abs / JSR / RTS / RTI | 3 / 6 / 6 / 6 |
| PHA / PLA | 3 / 4 |

Budget: an NTSC frame is about 29,780 CPU cycles (262 scanlines × 341 PPU dots ÷ 3). Vblank (scanlines
241-260) is about 2,273 cycles **[standard]**. OAM DMA alone takes 513 or 514 of them **[verified]**.

## 7. The stack
The stack lives at $0100-$01FF. Init code sets S = $FF (`LDX #$FF / TXS`), so the first push lands at $01FF
**[verified, Init code]**. A push writes then decrements S; a pull increments then reads. Every push must be
matched by a pull before `RTS`, or RTS returns to a garbage address.

## 8. Interrupts
- Reset: the CPU reads the 16-bit address at $FFFC and starts there.
- NMI: at the start of each vblank if PPUCTRL bit 7 is set; vector at $FFFA. It can't be masked by I.
- IRQ/BRK: vector at $FFFE; ignored while I = 1. NROM games usually leave IRQs off and point the vector at an
  `RTI`.
On NMI/IRQ the CPU pushes PC (high, low) and P, sets I, and jumps through the vector. `RTI` restores P and PC.
An NMI handler must save and restore any registers it changes (PHA / TXA / PHA ... / PLA / TAX / PLA), because
it interrupts the main loop at an unknown moment.

## 9. Pitfalls checklist
- Missing `#` (address instead of number) and vice versa.
- ADC without CLC, SBC without SEC.
- INC/DEC don't set carry, so they can't carry into a high byte by themselves; use `INC lo / BNE :+ / INC hi`.
- 8-bit wraparound: $FF + 1 = $00 (Z set, C set by ADC; INC sets Z but not C).
- Zero page indexing wraps: `LDA $F0,X` with X = $20 reads $0010, not $0110.
- Unbalanced stack in subroutines and interrupt handlers.
- Forgetting that `CMP` only compares; it doesn't store anything.
